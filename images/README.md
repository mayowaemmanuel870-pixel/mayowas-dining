# Images Folder

Place your restaurant images here with the following naming:

- `hero-salmon.jpg` - Hero/home page image
- `story-main-bakery.jpg` - Our Story main image  
- `story-secondary-arancini.jpg` - Our Story secondary (overlay)
- `menu-chicken-starters.jpg` - Chicken starter
- `menu-arancini-starters.jpg` - Arancini balls
- `menu-steak.jpg` - Steak with fries
- `menu-pasta.jpg` - Pasta dish
- `menu-lamb.jpg` - Lamb chops (optional)

All images should be optimized JPGs for web (under 300KB each for best performance).
